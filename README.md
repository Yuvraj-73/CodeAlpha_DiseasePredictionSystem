# AI Multi Disease Prediction System

This project predicts multiple diseases using Machine Learning algorithms.

## Diseases Included
- Diabetes Prediction
- Heart Disease Prediction
- Breast Cancer Prediction

## Algorithms Used
- Logistic Regression
- Random Forest
- SVM
- XGBoost

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- XGBoost

## Features
- Multi disease prediction
- ML model comparison
- Real-time predictions
- Streamlit web interface

## How to Run

Install dependencies:

pip install -r requirements.txt

Run app:

streamlit run app.py
